Raqmain website

Upload the contents of this folder to the web root of raqmain.ma.

The page is a static Arabic RTL website. No build step or backend is required.

Product assets and descriptions come from their main projects:
- Najeez: assets/najeez-icon.png is copied from najeez/assets/app_icon/icon-1024.png.
- DarJar: assets/darjar-icon.png is copied from
  darjar/assets/images/branding/google-play-app-icon.png.

Product descriptions use the wording supplied by the owner.
Privacy policies are copied from the main applications:
- Najeez: lib/features/settings/presentation/app_info_screen.dart (PrivacyScreen).
- DarJar: lib/app/localization/app_ar.arb (privacyPolicy entries).
Keep the website policies in sync when the applications change.

App Store URLs after uploading this folder to https://raqmain.ma:
- Najeez marketing: https://raqmain.ma/najeez/
- Najeez support: https://raqmain.ma/najeez/#support
- Najeez privacy: https://raqmain.ma/najeez/privacy.html
- DarJar marketing: https://raqmain.ma/darjar/
- DarJar support: https://raqmain.ma/darjar/#support
- DarJar privacy: https://raqmain.ma/darjar/privacy.html

Upload both product folders and assets along with the home page.
All pages are static and need no login, JavaScript, or server rewrite rules.
